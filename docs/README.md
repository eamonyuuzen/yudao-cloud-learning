## 使用规则

1. 主线始终由当前阶段计划决定，背景文档不自动变成实现需求。
2. 进入新阶段时，只从“数据治理概念渐进融入路线”取当前对应的一张概念卡。
3. 第一遍只理解概念在数据链路中的位置、输入输出和 Java 后端边界；真实实现需要它时再下钻。
4. 阶段结束后，只把经源码或运行证据验证的结论转入正式知识库。
