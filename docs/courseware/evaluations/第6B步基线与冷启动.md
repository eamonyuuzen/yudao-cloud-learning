## 开始前基线（15 分钟）

不看源码，回答三题：

1. 自然语言问题怎样经过“模型、运行器、工具、Java 后端”得到事实？

3. 最终答案正确，过程仍可能错在哪里？

每题只画箭头和一句理由。基线不要求正确，用来与阶段末对比。

## 7 天迁移

换成“只读查询数据治理规则”的新业务，不写框架代码，只交一张
[工具契约卡](../templates/工具契约卡模板.md)：

```text
哪些字段让模型选择
哪些身份字段来自运行时
模型能看到哪些结果
Java 后端保留哪些权限和数据范围
正常、无权限、下游不可用怎样结束
```

若只是把 `internship` 名字替换为 `governance`，但没有重新判断数据敏感性和
权限范围，不算完成迁移。

## 阶段末故障题

任选一个：

- 后端返回空响应 HTTP 403；
- 后端返回 200，但 CommonResult `code=403`；
- 后端返回 200，但 `data.list` 不是数组；
- 模型选择了正确工具，却把 `status` 填成 99。

要求：

```text
先预测第一故障边界
→ 运行测试
→ 对比 trace 和最终回答
→ 说明哪一层必须修、哪一层不该补救
```
