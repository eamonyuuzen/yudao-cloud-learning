# 第 6B 步导师脚本

> 这是导师侧答案与提示，不是用户第一入口。只有用户作答后，或同一连接点连续
> 两轮受阻时，才按层解锁。

## 使用规则

每一日只维持三件事：

```text
一个根问题
→ 一条可执行时间线
→ 一个能否预测失败的证据
```

提示顺序：

1. 指回静态角色，不给名词答案；
2. 给出动态事件的前后两格；
3. 最后才给真实文件与参考答案。

## Day 1：手动工具循环

第一动作：

```powershell
python examples/manual_agent_loop.py
```

用户先在输出上标出：

```text
谁决定
谁按名字调度
谁真正执行
谁持有业务事实
```

再做两个口头失败分支：

```text
name 不在 TOOLS
工具执行抛异常
```

预期压缩答案：

```text
模型输入：问题 + 工具定义
模型输出：tool name + arguments
Runner 接住 tool call
Runner 按 tool name 找函数
tool result 先进入 Runner 消息轨迹
Runner 再调用模型组织最终答案
```

不要在用户填空前展示这段。蛇形字段是 `page_no/page_size`；只有
`YudaoClient` 发 HTTP 时才转换成 `pageNo/pageSize`。

停止条件：用户能解释“模型提出调用意图，程序执行函数”，不追 SDK 内部状态机。

## Day 2：Java `@Tool`

先问：

> 只有 `@Tool` 这块标签，JVM 为什么不会凭空执行方法？还缺哪两个角色？

期待用户补出：

```text
启动扫描/注册
运行时按名称匹配/执行
```

第一入口：[PersonServiceImpl.java](../../../yudao-module-ai/yudao-module-ai-server/src/main/java/cn/iocoder/yudao/module/ai/tool/method/PersonServiceImpl.java)。

证据卡：[step06b-java-tool-registration.md](../reference-code/step06b-java-tool-registration.md)。

不用真实模型的最小证据：

```text
ToolCallbacks.from
→ 找到 ps_get_person_by_id
→ 检查 Schema
→ callback.call
→ 原 Java 方法返回 Fons
```

常见误解：

- `@Tool` 自己调用方法；
- Spring 容器会自动把所有 `@Tool` 发给所有模型；
- 工具名只是说明文字，不参与运行时匹配。

## Day 3：目录权限与业务权限

让用户沿真实链找到两个事实：

1. AI 角色通过 `toolIds` 决定“模型能选哪些工具”；
2. `UserProfileQueryToolFunction` 可接收任意 `id`，下游
   `AdminUserApiImpl#getUser` 又显式关闭数据权限。

核心追问：

> 能选这个工具，是否等于能查这个参数所指向的任意人？

期待答案：不等于。第一版更安全契约是 `query_my_profile()`，由运行时取当前
userId，而不是让模型自由填。

四层权限表：

```text
工具目录权限：Agent 可否选择能力
Token 身份：当前请求是谁
操作权限：可否执行 query
数据范围：能看哪些行
```

当前实习任务真实边界：

```text
已有：Token、tenant-id、internship:task:query
未有：按创建人、认领人或部门过滤的任务行级数据权限
```

## Day 4：工具契约

不要让用户手抄整个 Pydantic 类。让用户先填
[工具契约卡](../templates/工具契约卡模板.md)，AI 再映射代码。

必须由用户决定：

- 标题/状态/分页范围；
- 当前 v1 是“本租户全部任务”，还是要新增本人/部门数据范围；
- 哪些字段允许进入外部模型上下文；
- 401、403、空结果、超时的不同语义；
- 最大模型轮次、工具调用总数、工具并发数和超时预算。

实验室保守默认：

```text
模型可见：id、title、deadline、status
不返回：description
最大模型轮次：3
每请求业务工具总数：1
同时工具调用：1
工具超时：12 秒
整次运行超时：45 秒
```

它是可审查的默认答案，不代替用户最终业务决策。

五个真实模型案例：

```text
标题 + 状态
空结果
无 Token
无权限
无关闲聊
```

两个参数边界由确定性 Schema 单测验证：

```text
status=99
page_size=1000
```

不要混成“七个模型案例”，否则模型行为和确定性校验无法区分。
